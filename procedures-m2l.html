Vue d'ensemble technique

HAProxy

Répartition de charge HTTP/HTTPS en round-robin vers WEB1 et WEB2. Interface de monitoring sur port 8080.

Load Balancing Round-Robin Health Check

PfSense

Pare-feu multi-interfaces avec IDS Snort, NAT, règles de filtrage avancées entre DMZ publique, privée et réseau interne.

Firewall IDS Snort NAT

MariaDB

Réplication Master-Slave en temps réel. SGBD1 (Master) réplique vers SGBD2 (Slave) pour haute disponibilité.

Master/Slave Réplication HA

Serveurs Web

WEB1 (site vitrine) et WEB2 (sites ligues) avec Apache, PHP 8.2, WordPress connectés aux bases distantes.

Apache WordPress PHP 8.2

Nextcloud

Plateforme collaborative avec dossier par ligue (lecture/écriture) + dossier commun M2L (lecture seule).

Collaboration Partage Cloud

Serveur FTP

vsftpd en DMZ publique avec mode passif (ports 40000-40100). Accessible depuis Internet via NAT.

vsftpd Mode PASV Public
