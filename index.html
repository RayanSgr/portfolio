Infrastructure Réseau - Projet SISR

Conception et déploiement d'une infrastructure réseau sécurisée pour une PME de 50 employés. Premier projet SISR réalisé en 1ère année BTS SIO (Semestre 2).

Objectifs du projet

  • Segmentation réseau avec VLANs pour chaque département
  • Mise en place d'un firewall pfSense pour la sécurité
  • Configuration de serveurs Linux (DNS, DHCP, Web, Mail)
  • Monitoring avec Nagios pour la supervision
  • Mise en place de sauvegardes automatisées

Architecture

  • VLAN 10 : Administration (10.0.10.0/24)
  • VLAN 20 : Production (10.0.20.0/24)
  • VLAN 30 : DMZ (10.0.30.0/24)
  • Routage inter-VLAN avec ACL
  • Firewall pfSense avec règles strictes

Résultats

  • Infrastructure opérationnelle avec segmentation réseau
  • Sécurité renforcée avec firewall centralisé
  • Monitoring en temps réel de tous les services
  • Documentation technique complète

Technologies utilisées

Cisco IOS pfSense Linux Ubuntu Server Nagios VMware VLANs

Architecture Multi-Zones - BTS

Infrastructure réseau complète avec segmentation en 4 zones colorées pour sécurité optimale. Projet actuel de 2ème année BTS SIO (année complète 2025-2026).

Architecture en 4 zones

Zone Cyan - Réseau Filaire

  • Postes clients (PC, Laptop) avec accès filaire
  • Téléphones IP
  • Commutateurs Cisco avec VLANs
  • Plage IP : 172.16.X.X/24

Zone Orange - Serveurs d'Application

  • Serveur Asterisk (PABX IP)
  • Serveur DHCP
  • Active Directory
  • Supervision des services
  • Plage IP : 172.16.2.224/27

Zone Jaune - Stockage & BDD

  • Serveurs Web (WordPress)
  • Systèmes de stockage (SAN/NAS)
  • Serveurs de backup
  • Plage IP : 192.168.1.0/28

Zone Verte - DMZ

  • Serveur FTP public
  • Services exposés à Internet
  • Isolation maximale
  • Plage IP : 192.168.0.0/29

Sécurité & Résilience

  • Segmentation réseau : VLANs et pare-feu entre zones
  • Chiffrement : Protocoles sécurisés (SSH, HTTPS)
  • Redondance : Hyperviseur pour haute disponibilité
  • Supervision : Monitoring continu des services

Technologies

Cisco IOS VLAN 802.1Q Linux Ubuntu Asterisk WordPress MySQL FTP/SFTP
